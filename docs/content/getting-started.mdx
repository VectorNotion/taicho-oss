## 1. Sign in to your workspace

Open [cloud.taicho.ai](https://cloud.taicho.ai) and use the account provided by your workspace administrator. Your organization keeps its data, permissions, connections, and usage isolated from other Taicho customers.

If the login screen reports an origin or account error, contact [support@taicho.ai](mailto:support@taicho.ai) with the address you used and the time of the attempt.

## 2. Connect the work you already have

Choose the first source that matters to your outcome:

- For outreach, add leads through the REST API or MCP tools.
- For content, add the knowledge and source material your team already relies on.
- For nurture, begin with the audience and message sequence you want to operate.

Use the API or MCP when the source keeps changing so the workspace remains authoritative.

## 3. Give Taicho a concrete outcome

Use the Assistant to describe the result you need. A useful request names:

1. the outcome,
2. the audience or source material,
3. the channel or destination, and
4. any approval or timing limits.

Taicho uses that context to plan the work and show what happens next. Keep approvals where a human decision matters; let repeatable coordination run automatically.
