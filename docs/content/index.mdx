Taicho coordinates content, outreach, and nurture work around one shared operating context. These guides focus on the steps you need to complete inside the product.

## Start here

- [Getting started](/getting-started) — sign in, connect your existing work, and give Taicho a concrete outcome.
- Add leads through the REST API or MCP tools, then research and qualify them in Outreach.
- [Connect Taicho with MCP](/api) — use Taicho from Claude, Codex, Cursor, cloud automation, or another compatible client.
- [Explore the API reference](/api-reference) — inspect endpoints, parameters, OAuth scopes, request bodies, and response schemas.

<Callout title="Already have access?">
  Open [cloud.taicho.ai](https://cloud.taicho.ai) in another tab and follow the guides beside your workspace.
</Callout>

## One workspace, three fronts

**Content** covers research, drafting, review, and publishing. **Outreach** covers lead research, qualification, and engagement. **Nurture** covers adaptive email sequences and the approvals that keep them under control.

The same Brain, organization boundary, and activity history connect all three areas. You should not need to rebuild context every time work moves from one front to another.

## How these docs are maintained

Each page is a Markdown or MDX file. Navigation, page titles, the table of contents, and previous/next links are generated from the content metadata. The files are maintained alongside the product source in the Taicho repository.
